Each time you build a real raga, its medal lights up. How many can you find this session?

For the teacher: this lab builds symmetric scales — the same swaras going up and coming down — which is exactly how the 72 melakarta parents are formed. Real ragas can climb and descend differently (vakra) or borrow notes (bhashanga); that comes later, and the Raga Jukebox shows those. The raga dictionary used for discovery lives in one editable RAGA_DICT block at the top of the script — please verify each scale against Ganamrutha Bodhini before relying on it. Discoveries are remembered for this visit only.
